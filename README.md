### snow courier
### what is this?
- this is a game about delivering mails in a dark, snowy town!
- talk to the postman to start your journey
- go around town using your van and deliver mails

### why did i make this
- mainly to practice creating 3d maps, specifically the terrain3d addon in godot
- i also wanted to do some sound effects and background music, which i achieved in this project
- its not a complete game, just a repetitive submit and deliver loop, but it works

### controls

WASD - move

ARROWS - look around

E - interact

ESC - pause


### how to set this up locally

- download godot 4.6.2
- run `git clone https://github.com/derukaeru/creep-jam.git`
- open the folder in godot
- press f11 or the play button
